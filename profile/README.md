  # CSC2101 Topic D — Smart City Data Collection System

An AI-powered smart city data collection system using 360° street-view imagery, built as part of the CSC2101/2102 Professional Software Development module.

## Overview

This project explores how street-level 360° imagery can be captured and processed to support smart city data collection, combining computer vision, backend data pipelines, and a user-facing frontend.

## Repositories

| Repo | Purpose |
|---|---|
| [`Frontend`](../Frontend) | User interface and client-side application |
| [`Backend`](../Backend) | API, data storage, and server-side logic |
| [`ML`](../ML) | Machine learning models for image processing and analysis |
| [`csc2101-topicd-integration`](../csc2101-topicd-integration) | Integration layer tying the frontend, backend, and ML components together |

## Getting Started

Each repository contains its own setup instructions in its README. Clone the repos you need, or see the integration repo for running the full system end-to-end.

Rust · Python · SQL / MariaDB / MongoDB · Java
